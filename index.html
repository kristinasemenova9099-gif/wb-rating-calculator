Калькулятор рейтинга карточки Wildberries

Сколько новых отзывов нужно, чтобы поднять рейтинг карточки до целевого значения. Расчёт по двум моделям — простое среднее и приближение к реальному алгоритму ВБ, который взвешивает свежие отзывы сильнее старых.

База отзывов (необязательно)

Один раз загрузите сюда все ваши отчёты по отзывам (.xlsx/.csv с оценкой и датой каждого отзыва) — калькулятор соберёт из них базу по всем товарам с выбором по артикулу и точным рейтингом по реальным датам, без ползунка «средний возраст». База автоматически сохраняется в этом браузере — при следующем открытии страницы всё уже будет на месте, ничего заново загружать не нужно. Раз в месяц просто добавляйте сюда свежий отчёт за новый период — он домешается к сохранённому, а одинаковые отзывы (по колонке «ID») не задвоятся. Кнопка «Скачать для сайта» готовит файлы базы для команды: положите их рядом с index.html на хостинге — и у всех коллег база появится сама, без загрузки файлов вручную (см. подсказку под кнопкой). Всё считается и хранится прямо в браузере, никуда не отправляется.

Куда хотим прийти

Сколько дней карточка существует на ВБ (с первой продажи/первого отзыва). Отзывы не могут быть старше самой карточки — если она создана 3–4 месяца назад, все её отзывы ещё «свежие» и почти не затухают.
Влияет только на модель «с учётом ВБ». Подставили половину возраста карточки — если отзывы копились примерно равномерно, это разумная оценка; двигайте ползунок, если знаете точнее (например, всплеск отзывов после акции — отзывы моложе).

Как это считается

Простая модель: сумма всех оценок = текущий рейтинг × число отзывов. Считаем, сколько отзывов с новой оценкой нужно добавить, чтобы новое среднее достигло цели:

x = N × (цель − текущий) / (оценка_новых − цель)

Модель с учётом ВБ: по данным разборов алгоритма Wildberries, рейтинг — это взвешенное среднее, где вес отзыва затухает по мере старения: первые ~182 дня вес ≈ 1, дальше он снижается по формуле 100^(−(d−182)/1095) и к 2 годам доходит до 0 (учитываются максимум последние 2 года / 20 000 отзывов). Здесь мы оцениваем «эффективный» вес текущего массива отзывов через введённый средний возраст, а новые отзывы считаем свежими (вес 1) — и решаем то же уравнение относительно эффективного количества:

x = N × w(возраст) × (цель − текущий) / (оценка_новых − цель)

Это приближение: точный расчёт возможен только если знать дату и оценку каждого отзыва, которых обычно нет в открытом доступе продавца. Также ВБ округляет отображаемый рейтинг до 0,1 — этим объясняется опция округления выше.

Возраст карточки ограничивает, насколько старым вообще может быть отзыв (нельзя, чтобы отзыв был старше самой карточки), и служит подсказкой для «среднего возраста» — по умолчанию берём половину возраста карточки в предположении, что отзывы копились равномерно. Для карточек младше ~6 месяцев вес всех отзывов ещё близок к 1, поэтому разница между простой и точной моделью небольшая.
